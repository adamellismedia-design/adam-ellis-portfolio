## Preview

Open `index.html` in a browser. For convenience, a separate self-contained HTML preview is available in chat, placed next to the PDF so the resume link works.

## Publishing to GitHub and Cloudflare Pages

1. Create a GitHub repository and upload the contents of this ZIP into the repository root, retaining the exact filenames.
2. Connect Cloudflare Pages to that repository; choose a static site without a build command. Set the output directory to the repository root if prompted.
3. Verify the live site and test the PDF download link on desktop and mobile.

**Important:** Upload all **five website files plus the PDF resume**. The resume link will not work if the PDF is omitted or renamed.

No personal app projects, home address, forms, analytics scripts, or tracking have been included. Website remains unpublished until you deploy it.
